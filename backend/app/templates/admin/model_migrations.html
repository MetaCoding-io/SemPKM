Rollback order. Migrations reverse newest first. A later migration may have rewritten the same triples an earlier journal refers to, so reversing out of order would corrupt data rather than restore it. Only the most recent migration offers the button.

What rollback does not do. It reverses the migration's effect on your objects only. The model keeps its current schema artifacts and its recorded version, because the archive on disk is still the newer one. To return the model fully to an earlier release, roll its migrations back and then install the older archive.

A rollback is itself an event, so it appears in the event log as model.migrate.rollback, attributed to you.
