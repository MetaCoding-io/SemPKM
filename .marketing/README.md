# SemPKM Marketing Research

This directory contains evidence-backed marketing and positioning research for SemPKM.

## Contents

- `pkm-complaint-corpus.csv` — coded corpus of high-signal public discussions about structured PKM pain points.
- `product-marketing-principles.md` — durable product/marketing principles that have emerged repeatedly from the research.
- `jobs-pains-gains-positioning.md` — Jobs/Pains/Gains profile and positioning matrix for the initial beachhead: structured-PKM system builders, especially schema-strained Obsidian users.

## Research status

The corpus currently contains **59 coded discussions**, meeting the original working target of roughly 50–75 high-signal sources.

This is a **purposive research sample**, not a statistically representative survey. Sources were selected because they contain useful evidence about structured-PKM pain points, counter-signals, terminology, migration concerns, or object-model confusion. The dataset is appropriate for comparing recurring themes and sharpening positioning hypotheses; it should **not** be used to claim population prevalence (for example, "30% of PKM users have schema-drift problems").

The coding taxonomy includes:

- schema drift
- plugin maintenance
- capture friction
- rigidity
- relationship semantics
- migration
- portability
- querying
- complexity
- simplification response
- willingness to tinker

The corpus should remain append-only where possible: add additional high-signal discussions using the existing taxonomy, and change the taxonomy deliberately rather than opportunistically whenever a new anecdote appears.
