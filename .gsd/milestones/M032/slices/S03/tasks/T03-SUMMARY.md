# T03: Add builder config panel, save serialization, and CSS for form-group

**Added form-group builder config panel with repeatable shape entries (type picker + slot ID + edge linking), save serialization for nested shapes array, and CSS for form-group block rendering**

## What Happened

Added three pieces to complete the form-group dashboard block integration:

1. **Builder config panel** (`case 'form-group':` in `getTypeConfigHTML()`): Renders a `.form-group-shapes-config` container with a list of shape entries and an "Add Shape" button. Each shape entry includes a type IRI picker (reusing the existing `_builderClassSearch` autocomplete pattern), a label input, a slot ID input, and a collapsible edge-linking section with target slot and predicate IRI fields. A shared `_buildShapeEntryHTML()` function generates entry HTML for both initial populate (editing existing blocks) and dynamic add. Helper functions `_addShapeEntry()`, `_removeShapeEntry()`, and `_renumberShapeEntries()` manage the dynamic list.

2. **Save serialization** (special case in `_builderSave()`): After the generic `[data-key]` collection loop, checks if `typeName === 'form-group'` and overrides `block.config` by reading the `.shape-entry` DOM elements. Builds a `{shapes: [{type_iri, label, slot_id, edge_to?}]}` config object. Entries without a type IRI are skipped. Edge config is only included when both target slot and predicate are provided.

3. **CSS styles** in `workspace.css`: Block-level styles for `.dashboard-block-form-group` (scrollable, flex column), `.form-group-section` (border-left accent, collapsible), `.form-group-edge-badge` (pill badge), `.form-group-actions` (submit row), and status messages. Builder config styles for `.shape-entry` (card layout with header/remove button), `.shape-edge-config` (collapsible details). Lucide SVGs inside form-group sized per CLAUDE.md rule with `flex-shrink: 0`. GridStack `.suggestions-dropdown` z-index fix at 1000 to prevent dropdown clipping.
