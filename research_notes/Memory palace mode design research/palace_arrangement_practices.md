# Memory palace arrangement practices: how practitioners, historians and PKM authors lay out and use palaces

Researched 2026-11-03. Scope: palace architecture (rooms, routes, loci density, journey order, interference, reuse/retirement), historical room typologies, PKM spatial metaphors, existing palace software, and a mapping to SemPKM object types.

Access note: `artofmemory.com` and `forum.artofmemory.com` returned HTTP 403 to every direct fetch (WebFetch, curl with browser UA, and the r.jina.ai proxy). All Art of Memory forum material below comes from search-result snippets of named threads, not from reading the full threads. Treat quoted forum figures as individual practitioner opinions, not a surveyed consensus. The `mullenmemory.com` palace page returned only post excerpts; `cs.umd.edu` (Krokos PDF) returned 503, so Krokos figures come from secondary coverage.

## Key Question 1: Practitioner method — choosing a building, loci per room, walking order, spacing, images, review, reuse and ghosting

### Takeaway
There is no agreed loci-per-room number; practitioners report anywhere from 3 to 10 per room, with "mark every fifth locus" (from the *Ad Herennium*) being the one rule nearly everyone keeps. Routes are fixed, consistent (usually clockwise from the door), kept open-ended so they can grow, and dedicated palaces are preferred over reused ones whenever long-term retention matters, because reuse causes "ghosting" (image interference).

### Cited Findings

**Choosing a building**
- Ed Cooke to Joshua Foer (*Moonwalking with Einstein*): "The crucial thing was to choose a memory palace with which I was intimately familiar. 'For your first memory palace, I'd like you to use the house you grew up in...'" — [Time, quoting Foer](https://time.com/105434/how-to-develop-a-photographic-memory-4-easy-steps/)
- Cooke's instruction on route: "We're going to array the items of my to-do list one by one along a route that will snake around your..." (the childhood house) — [Goodreads reader note from *Moonwalking*](https://www.goodreads.com/notes/10754019-moonwalking-with-einstein/73876628-patti-kinsey/a01a59df-4624-4879-b964-ddf50f57e915)
- Nelson Dellis: "think of a familiar place (like your house, apartment, office, etc.) and imagine a mental pathway through it"; "most memory athletes use a technique called the 'memory palace'" — [CNBC interview](https://www.cnbc.com/2020/01/09/usa-memory-champion-nelson-dellis-how-to-improve-your-memory.html)
- Lynne Kelly (Psyche guide): use a familiar location such as your current home; well-known spaces (home, office, school, neighbourhood) are already encoded; one item per distinct spot in a fixed order (front door, wall/bookcase, table, window). Imagined palaces can be based on fictional settings — [Psyche, Lynne Kelly](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)
- Anthony Metivier: "when you consider each apartment, home or building a 'location,' then each individual room will be a station within that location"; "I like my stations to be as close together as possible" — [Magnetic Memory Method](https://www.magneticmemorymethod.com/?p=145)
- Metivier on alternative station placement: stations in each corner, on each wall, floor and ceiling (at least 10 per room), but using ceiling and floor "can lead to a convoluted journey" — [Magnetic Memory Method](https://www.magneticmemorymethod.com/?p=995)
- Metivier's advanced technique: virtual bookcases placed in a room, with a rule such as "all rooms with multiple bookcases have 10 shelves" — [Magnetic Memory Method](https://www.magneticmemorymethod.com/?p=995)
- Metivier worksheet guidance for beginners: "10 stations per Memory Palace is probably the better strategy", and "there is nothing wrong with starting with just one word in one room"; leave room to add about 10 more stations per location — [Memory Improvement Master Plan and Worksheets (PDF)](https://www.magneticmemorymethod.com/wp-content/uploads/2014/05/Memory_Improvement_Master_Plan_and_Worksheets.pdf)
- Forum advice that an empty, unfurnished house or room is a poor palace because the loci are too similar; furnish each room so loci are distinct — [Art of Memory forum, "Minecraft Memory Palace"](https://forum.artofmemory.com/t/minecraft-memory-palace/26328)

**Loci per room**
- Thread titled "10 Loci per room": one poster "tend[s] to average about ten loci per room"; another says "the rule of 5 you will hear fairly often is just most memory competitors know where each 5th loci is, not necessarily strictly 5 per room"; another sees "potential advantages to a fixed number per room, such as knowing if you missed one", while a third calls fixed counts "a luxury that may not be worth the cost" — [Art of Memory forum, "10 Loci per room"](https://forum.artofmemory.com/t/10-loci-per-room/30999)
- Another forum user: "many of them use 3 loci per room, 5 if they are really big" — [Art of Memory forum, "How to create a memory palace/journey"](https://forum.artofmemory.com/t/how-to-create-a-memory-palace-journey/30105)
- Cathy Chen (Mullen Memory, medical school use): for material with distinct stages (e.g. wound repair), each stage gets its own room "with several loci in each", keeping a sense of sequence between rooms — [Mullen Memory blog](https://mullenmemory.com/memory-palace)
- Alex Mullen's palace count is reported inconsistently: "around 100 memory palaces" in one profile vs. "one of Mullen's 20 or so memory palaces is his home in Oxford" in a 2016-era university profile — [Mic](https://www.mic.com/articles/138105/meet-the-millennial-with-the-world-s-best-memory); [Ole Miss news](https://web20.olemiss.edu/news/wordpress/wp-json/wp/v2/posts/55447)
- Mullen's home-palace example: images placed "alongside his mailbox, his driveway, his front door, etc." (i.e. exterior approach counts as loci) — [Mic](https://www.mic.com/articles/138105/meet-the-millennial-with-the-world-s-best-memory)
- Kelly's countries palace holds 220+ countries and dependencies added gradually, "a few per day"; her palaces total over 10 km of walking route; her pi palace covers the first 1,000 digits — [Psyche, Lynne Kelly](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)
- Kelly: "Mark every fifth location with a door, with four items between doors, to create a rhythm and avoid losing your place" — [Psyche, Lynne Kelly](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)
- Kelly orders items within a palace by an external sequence: population size for countries, the alphabet for alphabetic languages, radicals for Chinese characters — [Psyche, Lynne Kelly](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)

**Walking order (clockwise rule)**
- Forum poster starts by the door and chooses loci in a clockwise direction; others say direction matters less than consistency ("if you skip numbering, at least be consistent about how you move through them") — [Art of Memory forum, "Is it necessary to number loci?"](https://forum.artofmemory.com/t/is-it-necessary-to-number-loci/32323); [Art of Memory forum, "How I ensure order of close items"](https://forum.artofmemory.com/t/how-i-ensure-order-of-close-items-in-memory-palace/74513)
- A method-of-loci guide: sweeping clockwise or counterclockwise both work; "going clockwise is helpful, but it isn't necessary" — [memory-improvement-tips.com](https://www.memory-improvement-tips.com/memory-palace-to-memorize-a-list.html)
- Forum convention: go room by room left to right, and place items in each room in the same direction — [Art of Memory forum, "About memory palace"](https://forum.artofmemory.com/t/about-memory-palace/75037)
- "Perimeter method" for keeping track of loci is a named forum technique (thread exists; content not fetched) — [Art of Memory forum, "Keeping track of loci - the perimeter method"](https://forum.artofmemory.com/t/keeping-track-of-loci-the-perimeter-method/45158)
- Forum opinion: "you should never have a closed route in the MP, because you should be able to add new stations to the journey" (keep the route open-ended) — [Art of Memory forum, "Memory Palace - 30 day Challenge"](https://forum.artofmemory.com/t/memory-palace-30-day-challenge/50046)
- Metivier: design the palace in advance so you can "focus on learning rather than on navigating the palace" — [Magnetic Memory Method on Ad Herennium](https://www.magneticmemorymethod.com/rhetorica-ad-herennium/)
- Metivier teaches a "journey" that links multiple palaces, using the areas around the palaces (streets between buildings) — [Magnetic Memory Method](https://www.magneticmemorymethod.com/?p=145)

**Spacing**
- Metivier: the *Ad Herennium* advice to keep loci at regular intervals (Yates' "Herennium Pattern") is "very helpful in my own practice, though I do bend the rules from time to time" — [Magnetic Memory Method](https://www.magneticmemorymethod.com/rhetorica-ad-herennium/)
- Classical source value: "approximately thirty feet" (see Key Question 2) — [UT Austin Memoria, Ad Herennium III.xvi-xxiv (Caplan trans.)](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)

**Distinctive images**
- Cooke: "It's important that you deeply process that image, so you give it as much attention as possible" — [Brainscape flashcards quoting *Moonwalking*](https://www.brainscape.com/flashcards/moonwalking-with-einstein-6614619/packs/10493840)
- Kelly: vivid, striking, emotionally intense or absurd; use personal associations and puns; "don't resist the first image your mind offers"; non-visualisers should build a story per location instead — [Psyche, Lynne Kelly](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)
- Kelly's bestiary: "mostly uses her medieval bestiary to remember people's names, but it can be used to memorise anything that you can spell"; associate the beast with the first two letters of a name; purpose "merely to be memorable and fun" — [Kelly, Bestiary PDF](https://www.lynnekelly.com.au/wp-content/uploads/2024/09/kelly-bestiary.pdf); [Goodreads Memory Craft quotes](https://www.goodreads.com/work/quotes/70200084)
- UChicago study (Chiang & Bakkour, *Emotion*): participants toured Minecraft-built two-storey houses; a gloomy, overgrown "negative" palace produced better recall than a bright, flowered "positive" palace, and both beat no palace. Recommendations: use a familiar location, place items in specific spots, "be the architect", and consider a somewhat negative tone without overloading — [UChicago News](https://news.uchicago.edu/story/how-build-better-memory-palace)
- Metivier: imagine walls as "sticky" or as wax tablets, "ice, wood, fire, clouds" to strengthen placement — [Magnetic Memory Method](https://www.magneticmemorymethod.com/rhetorica-ad-herennium/)

**Review schedules**
- Dominic O'Brien's "Rule of Five" as used by Kelly: review immediately, then at 24 hours, one week, one month, three months; she reports lasting memory "even when she doesn't revisit a location for years" — [Psyche, Lynne Kelly](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)
- O'Brien's schedule is reported with varying intervals elsewhere (1 hour / 1 day / 1 week / 2 weeks / 1 month...), and a forum thread asks how to date the third review, indicating the book's timing is ambiguous — [Goodreads listing](https://www.goodreads.com/book/show/29637083); [Art of Memory forum, "question about Dominic's RULE OF FIVE review"](https://forum.artofmemory.com/t/question-about-dominics-rule-of-five-review/28412); [Newser](https://www.newser.com/story/179895/10-tricks-to-memorize-anything.html)
- Kelly: walk through palaces regularly, physically and in imagination, to add or revise — [Psyche, Lynne Kelly](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)

**Reuse and ghosting**
- Ghosting is "a very common occurrence usually referred to as 'ghosting' or image interference"; also nicknamed the "Ugly Sister Effect" — [Art of Memory forum, "How do i get rid of ghost images?"](https://forum.artofmemory.com/t/how-do-i-get-rid-of-ghost-images/53388); [Art of Memory forum, "Reusing memory palaces"](https://forum.artofmemory.com/t/reusing-memory-palaces/32078)
- "Alex Mullen recommends only using a palace once when long-term retention matters", though reuse is fine for a grocery list — [Art of Memory forum, "Can I re-use the same memory palace for different sets of information?"](https://forum.artofmemory.com/t/can-i-re-use-the-same-memory-palace-for-different-sets-of-information/86747)
- Resting periods: one user can reuse loci within an hour with mild ghosting; "after 24 hours the temporary memory journey is virginal and clean" — [Art of Memory forum, "Can you use a memory palace more than once a day without a ghosting effect?"](https://forum.artofmemory.com/t/can-you-use-a-memory-palace-more-than-once-a-day-without-a-ghosting-effect/94710)
- Rotation: for speed-cards practice, keep "maybe a half-dozen palaces and then cycle through them" — [Art of Memory forum, "Memory palace(s) for speed cards"](https://forum.artofmemory.com/t/memory-palace-s-for-speed-cards/40297)
- Competitors "often use the same loci for competitions and are therefore very fast at traversing them" (short-term reuse is standard in sport) — [Art of Memory forum thread on Alex Mullen](https://forum.artofmemory.com/t/how-does-people-like-alex-mullen-usually-remember-all-numbers-in-one-repetition-on-memory-league-in-competitions-that-goes-against-the-concept-of-spaced-repetition/87521)
- Some practitioners deny the problem ("never heard of nor experienced this effect"); others deliberately keep a short-term "notepad" palace they clean back to tabula rasa — [Art of Memory forum, "Is it possible to use a memory palace as a quick notepad, over and over?"](https://forum.artofmemory.com/t/is-it-possible-to-use-a-memory-palace-as-a-quick-notepad-over-and-over/43845)
- Metivier: dealing a deck of cards onto palace stations is one way to work around ghosting — [Magnetic Memory Method podcast](https://www.magneticmemorymethod.com/?p=4300)

### Inferences
- For a software palace holding durable knowledge (not competition data), the practitioner consensus points at one-object-per-locus, never overwriting a locus with a different object, and "retiring" a room by archiving it rather than clearing and refilling it. Ghosting is precisely the failure mode a PKM palace must avoid, so a UI should warn when a locus is reassigned.
- A sensible default density is 5 loci per room (small rooms) scaling to 10 (large rooms), with every fifth locus visually marked (a doorway, a statue, a numbered tile). The 5/10 cadence appears in Ad Herennium, Metivier's "10 stations per palace", Kelly's "door every fifth location", and competitors' "know where each 5th locus is".
- Routes should be linear, open-ended (room has an unused exit for growth), and consistently handed (clockwise from the entry door). For a 2D top-down level this translates to: entry door at bottom, loci numbered clockwise around the walls, exit on the far side.
- Exterior approaches (path, porch, garden) count as loci, so a level's outdoor tiles are usable space.
- Empty rooms are bad palaces: every locus should be a distinct piece of furniture or a distinct wall feature, not a bare floor tile.

### Gaps
- No full forum threads could be read (403), so per-user counts and the "perimeter method" details are unverified.
- No source gives a Memory League or competition-standard loci-per-room figure; competitors' numbers are anecdotal.
- O'Brien's exact review intervals vary across summaries; the primary text (*How to Develop a Brilliant Memory Week by Week*) was not accessible.
- Nothing found from Ed Cooke beyond the Foer-quoted instructions; no Memrise-era palace design guidance surfaced.

## Key Question 2: Classical and historical typologies — Ad Herennium, Quintilian, Camillo, Ricci, Bruno, Carruthers, cabinets of curiosity, songlines

### Takeaway
The classical rules are strikingly concrete (series of distinct, moderately sized, moderately lit, uncrowded places about thirty feet apart with every fifth marked, reusable like wax tablets); the Renaissance reinterpreted the palace as a *theatre* or *cabinet* that classifies all knowledge into a fixed grid (7x7 in Camillo, ordered object-rows in Quiccheberg); medieval monks used buildings they lived in (cloister, ark) plus numbered grids; Indigenous systems use landscape routes where each place carries a performed story and the route itself is "a table of contents".

### Cited Findings

**Rhetorica ad Herennium (c. 90-85 BCE), Book III.xvi-xxiv, Caplan translation**
- "it also seems best to arrange the backgrounds in a series", so one can proceed "in either direction from any background we please" — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- "each fifth background should be marked... if in the fifth we should set a golden hand, and in the tenth some acquaintance whose first name is Decimus, it will then be easy to station like marks in each successive fifth background" — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html); [confessionalbibliology.com excerpt](https://confessionalbibliology.com/2016/03/13/rhetorica-ad-herennium-on-memory/)
- "it will be more advantageous to obtain backgrounds in a deserted than in a populous region" (crowds of passers-by weaken images) — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- "backgrounds differing in form and nature must be secured"; "these backgrounds ought to be of moderate size and medium extent"; "neither too bright nor too dim"; "the intervals between backgrounds should be of moderate extent, approximately thirty feet" — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- "the backgrounds are very much like wax tablet or papyrus, the images like letters"; "the backgrounds, like wax tablets, should abide" (loci are permanent, contents replaceable) — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- Images should be "as striking as possible", "doing something", of exceptional beauty or singular ugliness; crowns, purple cloaks, blood, mud, red paint, comic effects aid recall — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- "The things we easily remember when they are real we likewise remember without difficulty when they are figments, if they have been carefully delineated" (imagined loci are legitimate) — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- Yates named the regular-interval advice the "Herennium Pattern" — [Magnetic Memory Method](https://www.magneticmemorymethod.com/rhetorica-ad-herennium/)

**Quintilian**
- *Institutio Oratoria* (c. 95 CE) retells the Simonides banquet-hall story: he identified crushed victims by remembering where each guest sat — [Wikipedia, Method of loci](https://en.wikipedia.org/wiki/Method_of_loci)

**Giulio Camillo's Theatre of Memory (1519-1544)**
- Wooden structure based on Vitruvius' Roman theatre; divided into seven gangways ("cloves") and seven levels of steps, defining 49 areas, each with a symbolic figure from mythology, Cabala or hermeticism; rests on seven pillars (Solomon's House of Wisdom); each gangway bears a planet image at its lowest level — [Socks Studio](https://socks-studio.com/2019/03/03/spatializing-knowledge-giulio-camillos-theatre-of-memory-1519-1544/)
- Camillo reversed audience and stage: a single spectator stands on stage and looks up at the tiers; the Theatre was to "locate and administer all human concepts, everything which exists in the whole world"; he called it *mens fenestrata* (a mind with windows) — [Socks Studio](https://socks-studio.com/2019/03/03/spatializing-knowledge-giulio-camillos-theatre-of-memory-1519-1544/)
- The seven levels run from nature toward art, ordered by creation chronology: Banquet and Cave (elemental), Gorgons and Pasiphae (the inner man), Sandals of Mercury and Prometheus (man as active agent, the arts, highest level); aim: "scholars into spectators" — [Wikipedia, Giulio Camillo](https://en.wikipedia.org/wiki/Giulio_Camillo)
- Viglius Zuichemus (1532) saw it in Venice: wooden, "marked with many images, and full of little boxes" — small boxes arranged in rows and levels holding papers under each image; Camillo called it "a built or constructed mind and soul... a windowed one" — [The Believer](https://www.thebeliever.net/the-theater-of-memory-a-cheap-facsimile-of-an-old-monastic-trick/); [Erasmus correspondence, dbnl](https://dbnl.org/tekst/eras001corr19_01/eras001corr19_01_0205.php)
- Camillo built a copy in Paris for Henry II; Erasmus was hostile ("tragedy in study", 5 July 1532) — [uni-Trier EGO](https://ego-plone.uni-trier.de/en/mediainfo/frances-a.-yates-189920131981-after-giulio-camillo-the-memory-theatre); [CEU thesis](https://www.etd.ceu.edu/2021/uremovic_judita.pdf)

**Matteo Ricci (1596, treatise for Ming governor of Jiangxi)**
- Ricci offered three options for memory locations: (1) real buildings one had been in or objects seen "with one's own eyes", which "are real, and can never be erased"; (2) wholly fictional "mental structures to be kept in one's head"; (3) half real, half fictional, e.g. a building one knew well "through the back wall of which one broke an imaginary door as a shortcut to new spaces", or a mental staircase added to a known building — [Spence excerpt via Magnetic Memory Method](https://www.magneticmemorymethod.com/?p=4980); [bourbakisme blog excerpt](https://bourbakisme.blogspot.com/2011/05/mp-memory-palace-giulio-camillo-lidea.html)
- Ricci "constructs the reception hall of his memory palace along these lines and orients it so that it faces south, in deference to the Chinese tradition that gives greatest honor to that direction" (Spence ch. 2) — [Schweitzer-online excerpt of Spence ch. 2](https://www.schweitzer-online.de/ebook/Spence/Memory-Palace-Matteo-Ricci/6610001056087/A75251399)
- Ricci explained the method "by converting four Chinese characters into images and placing them in an imaginary room"; Spence's book is organised around those four images "each fixed in its own place and described in sequence" — [LibraryThing](https://www.librarything.com/work/113804); [LRB, Peter Burke](https://www.lrb.co.uk/v08/n02/peter-burke/the-exotic-west)
- Ricci's palace is described as "a grand structure made up of a series of rooms each distinguished by unique architectural features like arches of columns" — [Harvard Advocate](https://theharvardadvocate.com/content/cartography-and-memory)

**Giordano Bruno**
- *De umbris idearum* (1582) uses concentric memory wheels; Yates reconstructed the wheel and the last section of the book describes the large wheel over 40 pages; Rita Sturlese's 1991 critical edition rejects Yates' "magical" reading — [Warburg Institute](https://warburg.sas.ac.uk/research-fellowships/research-projects/archived-research-projects/giordano-bruno/yates-brunos-mnemonics); [Wikipedia, Memory wheels](https://en.wikipedia.org/wiki/Memory_wheels)
- Yates' chapter "Giordano Bruno: The Secret of Seals" and plates from *Triginta Sigilli* (Thirty Seals) — [Yates, Art of Memory TOC](https://issuu.com/zimbali4/docs/yates_frances_a_the_art_of_memory)
- Forum view: the seals are "geometric patterns more than likely used in tandem with his memory art"; the thread notes it "wasn't shown how the memory seals worked other than serving as a memory palace" — [Art of Memory forum, Bruno's seals](https://forum.artofmemory.com/t/do-you-guys-know-anything-about-brunos-memory-seals/62947)

**Medieval memory arts (Carruthers)**
- *The Book of Memory* (1990) argues medieval culture was fundamentally memorial and uses Hugh of St Victor as a key figure — [Cambridge UP](https://www.cambridge.org/core/product/identifier/CBO9781107051126A016/type/BOOK_PART)
- Hugh's *De arca Noe* maps biblical teaching onto an imagined ark with compartments; concepts layered into exterior compartments; no physical images needed — [VoegelinView review of *Medieval Craft of Memory*](https://voegelinview.com/the-medieval-craft-of-memory-an-anthology-of-texts-and-pictures/)
- Hugh's "Three Best Memory Aids for Learning History" (*De tribus maximis circumstantiis gestorum*, c. 1130, for very young students at St Victor): compares a money-changer's divided pouch to a cloister holding many separate cells; fixes persons, places and dates as mnemonic headings; Carruthers says its "number scheme is most fully described by Hugh St. Victor in a text virtually overlooked by modern scholars" — [Cambridge chapter](https://www.cambridge.org/core/product/identifier/CBO9781107051126A016/type/BOOK_PART); [Carruthers, Diogenes essay on page layout](https://core-prod.cambridgecore.org/core/services/aop-cambridge-core/content/view/04CA875672A1479C9408A14C125CC048/S0392192100317618a.pdf/the-art-of-memory-and-the-art-of-page-layout-in-the-middle-ages.pdf)
- *The Craft of Thought* (Part I "An Architecture for Thinking"): monastic oratories/cloisters are buildings "that can be internalized, readily 'laid out' in distinct units in the mind and revisited"; architecture as "a metaphor for building spiritual understanding"; Italian edition titled *Machina memorialis* — [In Trust, Hamburger review](https://www.intrust.org/in-trust-magazine/summer-2000/paths-to-virtue); [BMCR 2000.02.14](https://bmcr.brynmawr.edu/?p=21791); [Cambridge UP](https://www.cambridge.org/9780521795418)

**Cabinets of curiosity and studioli**
- Samuel Quiccheberg, *Inscriptiones* (1565), written for Duke Albrecht V of Bavaria, "the first treatise on museums": describes how a princely Wunderkammer should be assembled "and the order in which objects should appear"; presents "an encyclopaedic museum built in the form of a theatre, in which various objects and images from the universe are arranged", with Camillo's theatre cited as a parallel influence — [Yale Books](https://yalebooks.co.uk/book/9781606061497/the-first-treatise-on-museums); [German History Intersections](https://germanhistory-intersections.org/en/germanness/ghis:document-273); [OsloMet journal](https://journals.oslomet.no/ar/article/view/3881)
- Prints of such cabinets "helped viewers learn the arrangement and mentally organize the collection"; the Italian counterpart is the studiolo — [UCM journal](https://revistas.ucm.es/index.php/ANHA/article/download/94248/4564456570805/4564456727570)

**Indigenous memory spaces (Kelly)**
- Songlines "follow the same pattern as Cicero's memory palaces", as do Native American pilgrimage trails, Pacific ceremonial roads and the Inca ceque system at Cusco — [Lynne Kelly, Psyche author page / 2017 essay](https://psyche.co/authors/lynne-kelly); [Kelly blog](https://www.lynnekelly.com.au/?cpage=1)
- "At each location, a song or story, dance or ceremony is performed that will always be associated with that particular location"; "a songline provides a table of contents to the entire knowledge system, one that can be traversed in memory as well as physically" — [Big Think](https://bigthink.com/?p=47642); [Mindscape 60 podcast page](https://preposterousuniverse.com/?p=2725)
- The Seven Sisters Songline covers more than 500,000 km²; Navajo elders identified 701 invertebrates from memory — [Psyche, Lynne Kelly](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)
- Luba *lukasa* memory board: a portable device whose physical features prompt structured knowledge; Kelly made her own; forum members describe it as "a memory palace in miniature" — [Brewminate / Kelly](https://brewminate.com/this-ancient-mnemonic-technique-builds-a-palace-of-memory/); [Art of Memory forum, Lukasa feedback](https://forum.artofmemory.com/t/lukasa-feedback/81603)
- Kelly's Stonehenge thesis (monuments as memory palaces for settled peoples who no longer walked songlines) is "a theory and it remains debated" — [The Courier](https://www.thecourier.com.au/story/4104488/the-palace-of-memory/); [Kirkus](https://kirkusreviews.com/book-reviews/lynne-kelly/the-memory-code)
- Scholarly caution (Tempone-Wiltshire & Yunkaporta, 2025): credit Kelly with showing place-based memory arose independently in many cultures, but warn against conflating Aboriginal cultural memory practice with the European method of loci — [PACJA article](https://pacja.org.au/article/143975-contributions-from-aboriginal-australian-psychology-songlines-memory-and-relational-knowledge-systems)
- Methods readers use most from *Memory Craft*: memory palaces, lukasa and the bestiary; Kelly prefers the term "memory spaces" over "memory palace" — [Kelly author site](https://www.lynnekelly.com.au/?page_id=25); [Goodreads blog "Memory Spaces"](https://www.goodreads.com/author_blog_posts/22222365-memory-spaces-what-they-are-and-why-they-re-important?tab=book)

### Inferences
- Two distinct historical typologies recur and both are useful defaults: (a) the **journey palace** (Ad Herennium, Ricci, Kelly, songlines): a linear route through differentiated places, best for sequences and large sets; (b) the **classified theatre/cabinet** (Camillo, Quiccheberg, Hugh's ark grid): a fixed grid of categories where position encodes classification, best for a taxonomy of concepts. A software palace can offer both as room templates (a "gallery corridor" vs. a "cabinet room" with an N x M shelf grid).
- Ricci's "half real, half fictional" option is the direct precedent for letting a user start from a familiar floor plan and knock imaginary doors into new wings. Camillo's "little boxes under each image" is the precedent for a locus being an image on the surface with the full text stored behind it (click to open).
- Classical rules that translate directly into level-design constraints: moderate room size, even lighting (no dark corners or glare), differentiated rooms (no identical tiles), deserted (no NPC crowds near loci), regular spacing, a visual marker every fifth locus, and loci that persist while their contents change.
- Kelly's "table of contents" idea suggests the main corridor of a palace should itself be a navigable index of the rooms.

### Gaps
- Yates' own text of *The Art of Memory* was not accessible; Camillo detail is secondhand (Wikipedia, Socks Studio, a CEU thesis).
- No source confirmed where exactly Ricci placed his four images in the reception hall (corners is plausible but unverified).
- Hugh of St Victor's numerical grid is referenced but not described in the sources found; Carruthers' Appendix A would be needed.
- Quiccheberg's actual class/row ordering was not retrieved in detail.

## Key Question 3: Modern knowledge-management spatial metaphors — Zettelkasten, PARA, Johnny Decimal, digital gardens, canvases, Notion homes

### Takeaway
PKM systems use spatial metaphors mostly at the level of containers (cabinet/drawer/folder, garden beds, boards) rather than walkable rooms; the recurring named zones are *inbox/capture*, *projects*, *areas*, *resources/library*, *archive*, and a *home/hub* page, while Zettelkasten spatiality is about *neighbours in a sequence* (Folgezettel) rather than places. No widely shared template was found that literally names rooms (study, library, lounge).

### Cited Findings
- Johnny Decimal's official analogy is a filing cabinet: "a computer is a room, an area is a filing cabinet, a category is a drawer, and an ID is a manila folder"; example cabinet "10-19 Life admin" with drawers "11 Me, 12 House, 13 Money, 14 Online, 15 Travel"; limits of 10 areas, 10 categories per area, 100 IDs per category — [Johnny Decimal docs](https://johnnydecimal.com/documentation/introduction); [Johnny Decimal, "the numbers"](https://johnnydecimal.com/documentation/the-numbers.md)
- PARA sorts by actionability into Projects, Areas, Resources, Archives; commonly combined "PARA for the high-level split, Johnny Decimal for numbering the areas and categories underneath" — [dsebastien.net](https://dsebastien.net/blog/2022-04-29-johnny-decimal)
- Notion second-brain guides: a "command-center" home page with filtered inbox and quick-add; "people capture but never process, which is where many of these systems stall"; warns against "treating your second brain like a library... not a place to store everything you'll 'maybe need someday'"; "everything will connect back to this page" (hub) — [Asian Efficiency](https://www.asianefficiency.com/productivity/second-brain-notion/); [techplex guide](https://techplex-blog.pages.dev/articles/notion-second-brain-guide)
- Commercial Notion templates with room-like sections: "Life HQ" with capture hub and inventory hub; "Habitat" with daily tracker, master "Brain" database, asset library; "6 dashboards for easy navigation" — [Gumroad Life HQ](https://opsandinsights.gumroad.com/l/NotionHomeManagementHub); [Gumroad Habitat](https://notionthings.gumroad.com/l/habitat); [Product Hunt Ultimate Second Brain](https://www.producthunt.com/products/ultimate-second-brain/launches/notion-second-brain-2-0)
- Digital garden (Maggie Appleton): "a collection of evolving ideas that aren't strictly organised by their publication date"; maturity stages Seedlings / Budding / Evergreen; critics note gardens are bounded, domesticated spaces and warn of "cultivated performance" — [Appleton via Obsidian Publish summary](https://publish.obsidian.md/bolinn/Digital+Gardens/Pioneering+Text/A+Brief+History+of+Digital+Gardening); [cssence, "Garden states"](https://cssence.com/2024/garden-states/); [inadeqtfuturs garden critique](https://garden-nog1af96v-inadeqtfuturs-projects.vercel.app/garden/00-rethinking-digital-gardening)

- A PKM article argues a consistently structured vault "is a digital memory palace", e.g. literature notes sit near their sources — [glukhov.org](https://glukhov.org/knowledge-management/tools/obsidian-for-personal-knowledge-management/)
- Kinopio deliberately has no AI features because "figuring out what things should be grouped together yourself is vitally important to building up your own spatial memory" (vendor claim) — [kinopio.club](https://www.kinopio.club)
- Milanote users create "a separate board for a new project or when they need more space, each with a blank canvas" — [toolradar Kinopio vs Milanote](https://toolradar.com/compare/kinopio-vs-milanote)
- Obsidian plugins: KMind Palace (Obsidian + SiYuan) binds a note to a piece of furniture or a single book on a shelf (a *locus*); a bookshelf can mirror a whole folder; build mode edits rooms, walls, doors, windows; palaces sit on islands, zoomable from town to archipelago to planet; FSRS spaced repetition; pins change colour with memory strength and neglected furniture gathers cobwebs; 4 scene themes, 5 pet species, 104 downloads at v0.1.1 — [Obsidian plugin page](https://community.obsidian.md/plugins/kmind-palace)
- "Memory Palace 3D" plugin renders Markdown notes "as interconnected rooms"; not manually reviewed by Obsidian staff — [obsidianstats](https://www.obsidianstats.com/plugins/memory-palace)
- Mine Palace (open source, April 2026 hackathon, built in ~3 hours): markdown vault to Minecraft; top-level folders become districts around a central hub; dated `YYYY-MM-DD.md` files become year > month > day alcoves; notes become shelves, lecterns, signs and written books in chiseled bookshelves; hosted on a server so others could walk it — [minepalace.vipul.xyz](https://minepalace.vipul.xyz/); [vipul.xyz writeup](https://vipul.xyz/2026/08/15/minepalace/)

### Inferences
- The zones people actually build in PKM tools, regardless of tool, are: inbox/capture, active projects, ongoing areas, reference/resources, archive, and a home dashboard. Those six are the safest default "rooms" because users already think in them; thematic rooms (study, lab, gallery) are rarer and more personal.
- The Mine Palace and KMind Palace mappings (folder = district/bookshelf, dated notes = calendar alcoves, note = book on shelf) are the only concrete note-to-geometry mappings found in the wild; both independently chose *library furniture* for notes and *time-indexed alcoves* for journals.
- Zettelkasten's "behind the parent" placement maps naturally onto shelf order within one room rather than onto separate rooms; Folgezettel chains are corridors, not buildings.
- The Notion guidance against "library hoarding" is a warning for palace design too: a Library room should surface what is in use, not become a dump.

- No Obsidian Canvas / Excalidraw community layouts with named zones were found; the "zone-based organization" page found was an AI-generated wiki and was not used.
- No Forte Labs or Johnny Decimal material uses a kitchen or house-room metaphor; the "kitchen" idea in the brief could not be sourced.
- Download/usage numbers for Memory Palace 3D were not available.

## Key Question 4: Memory palace software — what arrangements it offers and what users say

### Takeaway
Existing palace software splits into (a) pre-built 3D "worlds" with fixed loci counts and gamified SRS (memoryOS, 850+ loci; KMind Palace islands), (b) free-form VR/3D builders with pedestal templates (Munx/Macunx VR, with quincunx-shaped pedestal arrays), and (c) 2D list/SRS organisers (Palace Walk, Mnemopal, Memory Palace ASD). Reviews praise organisation and presence but complain about price and confusing navigation inside 3D palaces; controlled studies show virtual palaces work at least as well as imagined ones.

### Cited Findings
- **memoryOS** (co-created with 2x World Memory Champion Jonas von Essen): "Pre-made HD virtual Mind Palaces"; "850+ loci for mind storage space"; "Each palace room is a folder in your mind, so you know where every memory lives"; recall "come[s] back in order" as you walk; rewards, unlock new worlds, streaks, 10-minute micro-lessons (120-130+) — [memoryos.com](https://memoryos.com/). Ratings reported as 4.9/5 (7,600-11k reviews, self-reported on deal pages); complaints: "19,99 $ a month" and "navigation of the memory palace module to be unclear and frustrating" — [appshunter reviews](https://appshunter.io/ios/app/1553283646/reviews/5); [Android Authority deal page](https://deals.androidauthority.com/sales/memoryos-lifetime-subscription-student-plan)
- **Munx VR / Macunx** (Linguisticator, Dr Aaron Ralby; Steam, released 20 June 2018, free): draw fences, walls, rooms, floors; four predefined pedestal structures "Single, Quincunx, Quincunxqrd, and Macunx"; import images (Pixabay) and 3D models (Google Poly) in-headset; "Mostly Positive", 77% of 18 reviews — [Steam](https://store.steampowered.com/app/871490). Earlier marketing: three modes "teach users how to design bespoke palaces, organise complex subjects into images and build palaces for others to use"; Guided mode offers subject modules — [LS:N Global](https://www.lsnglobal.com/news/article/19825/virtual-memory). A 2025 academic paper by Ralby and Mentzelopoulos covers the project's theory — [iLRN publication](https://publications.immersivelrn.org/index.php/academic/article/view/576)
- **KMind Palace** (Obsidian/SiYuan): see Key Question 3; recall mode flies "from stop to stop along a route, thinking before revealing each note"; a pet leads the way — [Obsidian plugin page](https://community.obsidian.md/plugins/kmind-palace)
- **Palace Walk** (iOS, free): reviewer calls it "the best app i have found to organize memory palaces and peg systems" — [App Store](https://apps.apple.com/us/app/memopala/id1583677186)
- **Mnemopal** (iOS/Android, free): memory palace builder + SRS; imports Anki decks; cards attach to palace locations or are reviewed as decks; palace items can be "crammed in a set order, which can be changed, or reviewed based on their SRS level"; modified SM-2 — [App Store](https://apps.apple.com/sl/app/id6749877076); [developer Reddit post (snapshot)](https://reddit.sentinel-team.org/posts/1ro2rix/snapshots/2026-03-11T11%3A29%3A32.380727Z)
- **Memory Palace ASD** ($2.99), **RecallSpace** (iOS 26, "turns your surroundings into a digital memory palace"), **Topos: AI Memory Palace** (AR), **Lociform**, **Mind Palace: Memory Trainer**, **Roman Room** exist with too few ratings to show an overview — [App Store ASD](https://apps.apple.com/app/id6754575512); [App Store RecallSpace](https://apps.apple.com/ca/app/recallspace/id6774547087); [Product Hunt Topos](https://www.producthunt.com/p/topos/topos); [App Store Lociform](https://apps.apple.com/app/id6800037106)
- **Minecraft palaces**: forum members call Minecraft "undoubtedly the king for massive memory palaces" while others report "it's not working that great"; one shared design has five floors "each of which can have several rooms, which will have several loci", a roof, four towers and two bridges — [Art of Memory forum, best video games for palaces](https://forum.artofmemory.com/t/of-the-best-video-games-for-creating-massive-memory-palaces/96606); [Art of Memory forum, Minecraft Memory Palace](https://forum.artofmemory.com/t/minecraft-memory-palace/26328); Harry Potter/Hogwarts palaces in Minecraft are a recurring hobbyist project — [r/memorypalace mirror](https://lr.eu.psf.lt/r/memorypalace/comments/1faasa7/harry_potter_memory_palace_in_minecraft)
- Fiction video games with "mind palace" mechanics: *The Sinking City* (2020), *Twin Mirror* (2020), *Alan Wake II* (2023, Saga Anderson's "Mind Place") — [Wikipedia, Method of loci](https://en.wikipedia.org/wiki/Method_of_loci)
- **Research on virtual palaces**: Krokos, Plaisant & Varshney (UMD, *Virtual Reality* 2018/2019): 40 participants; two purchased environments (medieval town, ornate palace), 21 famous faces hand-placed in each; HMD gave "8.8 percent improvement overall in recall accuracy" over desktop, statistically significant; 40% of participants scored at least 10% higher in VR; nearly all preferred VR, crediting presence — [Ryan Schultz summary](https://ryanschultz.com/2019/07/29/); [UMD MPower](https://mpower.maryland.edu/?p=6156); [paper PDF](https://obj.umiacs.umd.edu/virtual_reality_study/10.1007-s10055-018-0346-3.pdf)
- Legge et al. (2012): virtual-palace users outperformed mental-palace users (statistically significant), per Krokos' citation — [Ryan Schultz / Krokos](https://ryanschultz.com/2019/07/29/)
- O'Grady & Yildirim (HCII 2019 poster): VR and traditional method of loci "comparable", i.e. virtual palaces "as effective as traditional, imaginative technique, but not more effective" — [Springer via unpaywall](https://unpaywall.org/10.1007%2F978-3-030-23528-4_56)
- Fassbender & Heiden (2006) "The Virtual Memory Palace" placed icons at locations in a 3D architectural model; one participant recalled all 10 items ("Oh, that is easy now") — [Teacher Toolkit](https://www.teachertoolkit.co.uk/2024/04/30/memory-palace/)
- Chiang & Bakkour (UChicago, *Emotion*): Minecraft two-storey houses; negative-valence house beat positive; both beat control — [UChicago News](https://news.uchicago.edu/story/how-build-better-memory-palace)

### Inferences
- Every product that gained traction gave users *pre-built* spaces with fixed loci (memoryOS's 850 loci, Macunx's pedestal arrays, KMind's furnished houses). Blank-canvas builders (Munx VR with 18 reviews) stayed niche. A default set of furnished rooms matters more than a flexible editor.
- Users of 3D palaces report getting lost ("navigation... unclear and frustrating"). A 2D top-down map avoids this, and should still provide an always-visible route/minimap.
- The Macunx "quincunx" pedestal (5 points: four corners plus centre) is a practitioner-designed locus cluster matching the rule-of-five; a 2D room template of 5 loci (4 corners + centre feature) or 2 quincunxes (10) is defensible.
- Spaced repetition integrated with the walk (KMind's cobwebs on neglected furniture, memoryOS's SRS) is the common software addition to the classical method; a PKM palace can show "dust" on loci not visited recently.
- Study evidence (Legge, Krokos, O'Grady) supports that a visible virtual palace does not harm recall versus imagination and may help; the benefit is modest (single-digit %), so the palace's value for PKM is mostly navigation and re-encounter, not raw memorisation.

### Gaps
- Could not read the Mnemopal website or the Memory Palace Builder app reviews; no Android-specific review data found.
- No reviews of Librarium were found; the name did not surface in any search.
- No Product Hunt or GitHub data on "Recall" or "Mempalace" web apps surfaced.

## Key Question 5: Mapping SemPKM object types and relationships to rooms and connectors, and where practitioner advice contradicts the mapping

### Takeaway
Practitioner precedent supports type-to-room zoning (Chen's "one stage per room", Mine Palace's "folder per district", memoryOS's "room as folder"), and historical precedent supports a library for sources, a theatre/cabinet for classified concepts, and time-indexed alcoves for events. The main contradictions are: practitioners order by *sequence*, not category; they warn against bare, undifferentiated rooms; they warn against reusing a locus for new content; and they place one item per locus, which clashes with open-ended PKM collections.

### Cited Findings (precedents that support each mapping)
- Rooms as stages/categories: Chen gives "each stage... its own room, with several loci in each" to keep sequence between rooms — [Mullen Memory](https://mullenmemory.com/memory-palace); memoryOS: "Each palace room is a folder in your mind" — [memoryos.com](https://memoryos.com/); Mine Palace: "top-level folders become districts" — [minepalace.vipul.xyz](https://minepalace.vipul.xyz/)
- Sources/papers as library: KMind binds a note to "a single book on a shelf" and "a bookshelf can mirror a whole notebook or folder" — [Obsidian plugin page](https://community.obsidian.md/plugins/kmind-palace); Mine Palace stores notes as written books in chiseled bookshelves — [vipul.xyz](https://vipul.xyz/2026/08/15/minepalace/); Metivier's virtual bookcases with 10 shelves — [Magnetic Memory Method](https://www.magneticmemorymethod.com/?p=995); a PKM author: "literature notes sit near their sources" — [glukhov.org](https://glukhov.org/knowledge-management/tools/obsidian-for-personal-knowledge-management/)
- Events as calendar architecture: Mine Palace diary mode makes "years, months, and day alcoves" — [minepalace.vipul.xyz](https://minepalace.vipul.xyz/); Hugh of St Victor fixed "persons, places, and dates" as the memory headings for history — [Cambridge chapter](https://www.cambridge.org/core/product/identifier/CBO9781107051126A016/type/BOOK_PART)
- People as a hall of figures: the *Ad Herennium* uses "some acquaintance whose first name is Decimus" as the tenth-locus marker (people as landmarks) — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html); Kelly uses her bestiary chiefly "to remember people's names" — [Goodreads Memory Craft quotes](https://www.goodreads.com/work/quotes/70200084); Krokos' experiment placed famous faces on walls of a palace — [Ryan Schultz](https://ryanschultz.com/2019/07/29/)
- Concepts as classified gallery/theatre: Camillo's 49 places with a mythological figure per cell and texts in boxes beneath, for "all human concepts" — [Socks Studio](https://socks-studio.com/2019/03/03/spatializing-knowledge-giulio-camillos-theatre-of-memory-1519-1544/); Quiccheberg's ordered cabinet rows — [Yale Books](https://yalebooks.co.uk/book/9781606061497/the-first-treatise-on-museums)
- Inbox/capture as the first zone: Notion second-brain guides centre on an inbox and warn that systems stall when people "capture but never process" — [Asian Efficiency](https://www.asianefficiency.com/productivity/second-brain-notion/)
- Doors as structural connectors: Ricci's half-fictional palace "through the back wall of which one broke an imaginary door as a shortcut to new spaces, or a mental staircase added to a known building" — [Magnetic Memory Method / Spence](https://www.magneticmemorymethod.com/?p=4980); Kelly uses doors as every-fifth markers — [Psyche](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information); Camillo's *mens fenestrata*, "a mind endowed with windows" — [Socks Studio](https://socks-studio.com/2019/03/03/spatializing-knowledge-giulio-camillos-theatre-of-memory-1519-1544/)
- Journeys between palaces: Metivier links palaces via the streets around them — [Magnetic Memory Method](https://www.magneticmemorymethod.com/?p=145); songlines as "a table of contents to the entire knowledge system" — [Big Think](https://bigthink.com/?p=47642)

### Cited Findings (practitioner advice that contradicts or constrains the mapping)
- Loci are for *ordered* material; the Ad Herennium insists on a series one can traverse "in either direction from any background" — a typed room with unordered contents loses this — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- One item per locus; images must differ. Krokos placed exactly one face per spot — [Ryan Schultz](https://ryanschultz.com/2019/07/29/); Kelly: "one item at each distinct spot" — [Psyche](https://psyche.co/guides/how-to-build-a-memory-palace-to-store-and-revisit-information)
- Rooms must be differentiated and furnished; "an empty, unfurnished house or room doesn't make for an effective memory palace because the loci would be too similar" — [Art of Memory forum](https://forum.artofmemory.com/t/minecraft-memory-palace/26328); Ad Herennium: "backgrounds differing in form and nature must be secured" — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- Do not reassign a locus if retention matters (Mullen: use once) — [Art of Memory forum](https://forum.artofmemory.com/t/can-i-re-use-the-same-memory-palace-for-different-sets-of-information/86747)
- Avoid crowded places: "more advantageous to obtain backgrounds in a deserted than in a populous region" — a "lounge for people" full of avatars could be counter-productive as a *memorisation* room — [UT Austin Memoria](https://laits.utexas.edu/memoria/Ad_Herennium_Passages.html)
- Chen and Mullen only palace things they "want to say fluently", not "lists they can write down" — most PKM content would not be palaced by a competitor — [Mullen Memory](https://mullenmemory.com/memory-palace)
- Luhmann: "the actual place is of lesser importance and what matters is that you can find something when you need it" (Zettelkasten resists fixed topical rooms) — [Zettelkasten forum](https://forum.zettelkasten.de/discussion/comment/24851)
- Metivier: ceiling/floor stations make "a convoluted journey"; keep stations close and the route simple — [Magnetic Memory Method](https://www.magneticmemorymethod.com/?p=995)
- PKM caution against "library" hoarding — [techplex guide](https://techplex-blog.pages.dev/articles/notion-second-brain-guide)

### Inferences (proposed mapping, grounded in the above)
- **Entrance hall / mailroom = Inbox and fleeting notes.** Every PKM system found starts with a capture zone; put it at the door so the walk begins by processing it. Unprocessed items should visibly pile up (Notion's "capture but never process" failure made visible).
- **Library = Sources, papers, literature notes.** The strongest precedent (KMind, Mine Palace, Metivier's bookcases). Shelves of 10 (Metivier) give a natural locus grid; literature notes sit on the same shelf as their source.
- **Study / scriptorium = Permanent notes and the Zettelkasten chain.** Order along the shelf by Folgezettel (behind the parent), not by topic; this is a corridor of sequence, which is what the method of loci is good at.
- **Gallery or cabinet room = Concepts.** Camillo/Quiccheberg precedent: a grid where position encodes classification, each cell an image with text "in the box beneath". Suits a typed-concept hierarchy from the ontology.
- **Workshop / office = Projects; task board or kitchen = Tasks.** Chen's "one room per stage" supports a project room whose loci are the project's stages or tasks in order; the workshop metaphor was not found in practitioner sources and is a design choice, not a tradition.
- **Clock tower / calendar cloister = Events.** Mine Palace's year/month/day alcoves and Hugh's dates-as-headings support a time-indexed room with regularly spaced alcoves.
- **Hall of portraits = People (CRM).** Faces on walls (Krokos), acquaintances as markers (Ad Herennium), bestiary for names (Kelly). Note the contradiction: this should be a quiet portrait hall, not a crowded lounge, if memorisation is the goal; a "lounge" works if the goal is social browsing.
- **Vault / archive = retired palaces and archived notes.** Reuse causes ghosting, so archive rooms rather than clearing them; practitioners rotate palaces instead of overwriting.
- **Connectors:** doors for hierarchical/containment relations (Ricci's door knocked into the back wall), corridors for sequence (Folgezettel, project stages), stairs for abstraction level (Camillo's grades rise from elemental to arts), windows for weak or cross-reference links (Camillo's *mens fenestrata*: see but not walk). The outdoor path between buildings is Metivier's inter-palace journey and Kelly's songline index.
- **Density defaults:** 5 loci per small room, 10 per large room, a marker (door, statue, numbered floor tile) every fifth locus; one object per locus; rooms visually distinct (different floor texture, colour, furniture set).

### Gaps
- No practitioner source discusses memory palaces for *typed knowledge graphs*; the mapping is inference from precedents, not documented practice.
- No source quantifies how many rooms a single palace should have before it is split into a second building.
- "Workshop", "lab", "kitchen" and "garden" room metaphors were not found in any mnemonic or PKM source; they are design choices.

## Key Question 6: Social use — shared or taught palaces, memory theatre as performance, group memory in oral cultures

### Takeaway
Palaces are overwhelmingly personal, but there are real precedents for sharing: competitors trade "journeys" on forums and in software when the layout is "compatible with your system"; Camillo and Macunx explicitly built palaces for other people to use; teachers hand students a shared photo or building; and in oral cultures the route is a communal, performed, often graded knowledge system. The historical pattern is that shared palaces work when the *structure* is shared and the *images* stay personal.

### Cited Findings
- Forum: using another person's journey "can work if the other person's memory palace is compatible with your system" (e.g. a preference for clockwise); "there are some threads here in the forum where people share their journeys"; "in the memory palace software, people can share memory journeys with each other" — [Art of Memory forum, "Shared Mnemonic Journeys"](https://forum.artofmemory.com/t/shared-mnemonic-journeys-using-anothers-memory-journey/56109)
- A forum member runs a "memorise & socialise" group "that anyone can join", building the method of loci into social activities — [Art of Memory forum, "Memory Palace - Method of Loci users"](https://forum.artofmemory.com/t/memory-palace-method-of-loci-users/29379)
- Macunx VR's stated third mode: "build palaces for others to use"; Guided mode "walking users step-by-step through the process of creating memory palaces to learn these subjects" — [LS:N Global](https://www.lsnglobal.com/news/article/19825/virtual-memory)
- Mine Palace author "hosted the world on a remote server so others could connect and navigate it" — [vipul.xyz](https://vipul.xyz/2026/08/15/minepalace/)
- Camillo built his theatre as a device for a patron (showed it to Viglius in Venice; built a copy in Paris for Henry II "in return for money"); it was designed for "a single spectator standing on the stage" and aimed to turn "scholars into spectators" — [uni-Trier EGO](https://ego-plone.uni-trier.de/en/mediainfo/frances-a.-yates-189920131981-after-giulio-camillo-the-memory-theatre); [Socks Studio](https://socks-studio.com/2019/03/03/spatializing-knowledge-giulio-camillos-theatre-of-memory-1519-1544/); [Wikipedia](https://en.wikipedia.org/wiki/Giulio_Camillo)
- Ricci wrote his treatise to teach Chinese literati to build their own palaces, orienting the hall south for Chinese honour conventions — [Schweitzer-online Spence excerpt](https://www.schweitzer-online.de/ebook/Spence/Memory-Palace-Matteo-Ricci/6610001056087/A75251399); [The Lectern review](https://thelectern.blogspot.com/2014/03/the-memory-palace-of-matteo-ricci.html)
- Quiccheberg's cabinet treatise and the prints of cabinets "helped viewers learn the arrangement and mentally organize the collection" (a shared, published arrangement) — [UCM journal](https://revistas.ucm.es/index.php/ANHA/article/download/94248/4564456570805/4564456727570)
- Classroom: Teacher Toolkit suggests "students could use their school or a photograph they recognise and love" with ten prompts tied to features of a shared market photo; each student charts their own route and images; teachers encouraged to have students "revisit and expand their palaces over time" — [Teacher Toolkit](https://www.teachertoolkit.co.uk/2024/04/30/memory-palace/)
- Oral cultures: "at each location, a song or story, dance or ceremony is performed that will always be associated with that particular location, physically and in memory" (communal performance anchors the route) — [Big Think](https://bigthink.com/?p=47642)
- Kelly's monuments thesis: structures like Stonehenge "served as memory palaces, encoding social knowledge over extended periods of time", built "as memory aids for ancient elders" (group, intergenerational memory) — [Mindscape 60](https://preposterousuniverse.com/?p=2725); [The Courier](https://www.thecourier.com.au/story/4104488/the-palace-of-memory/)
- Scholarly caution: do not conflate Aboriginal relational knowledge systems with the individual European method of loci — [PACJA 2025](https://pacja.org.au/article/143975-contributions-from-aboriginal-australian-psychology-songlines-memory-and-relational-knowledge-systems)
- Business use: each part of a presentation tied to a location so a speaker recalls points in order (a performed walk-through) — [FourWeekMBA](https://fourweekmba.com/memory-palace/)
- Kelly on a palace shared with a non-human companion: she walks her memory palaces with her dog, one stop being a shop that represents Vanuatu (real neighbourhood as palace) — [Kelly author site](https://www.lynnekelly.com.au/?page_id=25)

### Inferences
- Sharing works at the level of **structure** (floor plan, route, shelf grid) while **images and contents remain personal**: every successful shared case (forum journeys, Macunx palaces for others, teacher's shared photo, Quiccheberg's published order) shares the container, not the mnemonic images. For SemPKM this argues for shareable room *templates* and shareable *routes*, with per-user contents.
- "Compatibility" means handedness and density: a shared template should state its walking direction and loci count so a recipient can judge fit.
- Oral-culture precedent suggests a "performance" mode: a guided tour that narrates each locus in order (a presentation or teaching walk), the modern equivalent of the memory theatre or the songline sung at each site.
- Hosting a palace for others to walk (Mine Palace, Macunx) is the closest existing analogue to a multi-user SemPKM palace.

### Gaps
- No evidence was found of mnemonists routinely sharing fully populated palaces for long-term knowledge; sharing is rare and mostly for competition journeys.
- The "Shared Mnemonic Journeys" thread could not be read in full (403); detail on how shared journeys are formatted is missing.
- No sources on Memory League's own palace-sharing features; Memory League appears only as a competition format.
